YOLO-BOLO License Plate Detection System

A real-time capable computer vision pipeline that detects license plates in video footage, reads the serial number using OCR, and cross-references against a watchlist and blacklist. Generates a full incident report after each run.

What it does

End-to-end plate intelligence

From raw camera footage to a timestamped incident report — fully automated.

🎯
Plate Detection
YOLOv11 nano model trained on 27,000+ US and international plate images localizes plates in every frame with 0.93 mAP50 accuracy.
🔤
Serial OCR
12 preprocessing variants (CLAHE, threshold, sharpening) feed EasyOCR. A majority vote + length scoring system selects the best read.
🔍
Zone Isolation
The central 55% band of each plate crop is extracted before OCR, removing state names, slogans, and registration stickers from the read.
⚠️
Watchlist & Blacklist
Every detected plate is checked against configurable CSV lists with vehicle info. Fuzzy matching handles minor OCR misreads automatically.
📋
Incident Logging
Three timestamped CSVs are generated per run — all plates, watchlist matches, and blacklist alerts — with frame numbers and confidence scores.
📊
HTML Report
A self-contained HTML report auto-generates after each inference run with stat cards, color-coded tables, and a pulsing alert banner for blacklist hits.
How it works

The pipeline

Five stages from raw frame to logged result.

01
Detection
YOLOv11 runs on every frame and returns bounding boxes for each plate
02
Crop & Zone
Plate is cropped with padding, then trimmed to the serial number band only
03
OCR
12 preprocessing variants run through EasyOCR with an allowlist of A–Z 0–9
04
Scoring
Majority vote + confidence + length score selects the best candidate
05
Match & Log
Result is checked against lists, logged to CSV, and written to the report
In action

Demo & output

Green box — Watchlist
Known vehicles on the watchlist are highlighted green with make, model, and year shown inline on the frame.
🔴
Red box — Blacklist alert
Blacklisted plates trigger a red bounding box and are immediately logged with the alert reason from the CSV.
🟡
Yellow zone box — OCR region
A secondary box shows exactly which band of the plate is being read by OCR — useful for debugging and demonstration.
🟠
Orange box — Unknown
Plates not matched to any list are logged as unknown and included in the all-plates table of the report.
